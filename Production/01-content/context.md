# 01-content — Context

## What this folder is for

This folder holds one markdown file per section of the Pecuvate landing page. Each file documents:
- The purpose of that section (from the context guide)
- Content gaps that must be filled before building
- Approved copy once decisions are made

## Process

Fill in all section files here before any design or build work begins. Content drives design, not the other way around.

## Files in this folder

- `hero.md` — Header / Hero section
- `what-pecuvate-does.md` — Venture studio model explanation
- `ecosystem.md` — Pecuvate, Zenium Studios, Resorz
- `thinking-and-insights.md` — Medium blog feed section
- `connect.md` — Contact / CTA section
- `footer.md` — Footer content

## Status key

Use these markers in each file:
- `[ ]` — Not yet decided
- `[draft]` — Draft written, not approved
- `[approved]` — Final, ready to build
