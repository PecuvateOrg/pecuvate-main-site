# 03-technical — Context

## What this folder is for

This folder documents all technical decisions and requirements for the Pecuvate landing page build. Decisions made here directly affect the code structure and what gets deployed to Netlify.

## Process

Resolve these decisions before writing any code. Technical choices here must align with:
- The Netlify deployment setup in `04-deployment/`
- The content requirements in `01-content/`

## Files in this folder

- `stack-and-build.md` — Framework, build tool, and output folder decisions
- `medium-integration.md` — How Medium posts are fetched and displayed
- `requirements.md` — Performance, accessibility, and responsive design requirements

## Status key

- `[ ]` — Not yet decided
- `[decided]` — Decision made, ready to implement
