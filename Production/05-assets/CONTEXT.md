# 05-assets — Context

## What this folder is for

This folder tracks all assets required for the Pecuvate landing page — what's needed, what's been provided, and where files live.

## Process

1. Fill in `asset-tracker.md` with all required assets
2. Mark each as received or pending
3. Once received, note the filename and format
4. Ensure all assets are optimised before use in the build

## Files in this folder

- `asset-tracker.md` — Complete list of required assets and their status

## Where asset files go

Asset files themselves (SVGs, PNGs, etc.) are stored in the code repository under `/assets/` — not in this documentation folder.
