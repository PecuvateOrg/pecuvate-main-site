# 02-design — Context

## What this folder is for

This folder documents all design system decisions for the Pecuvate landing page. Nothing gets built until the design decisions in these files are resolved.

## Process

1. Resolve `visual-direction.md` first — it sets the design philosophy
2. Then define `color-and-typography.md` — the core system tokens (superseded: see `design-system/MASTER.md`)
3. Then `design-system.md` — spacing, grid, components, and interaction patterns (superseded: see `design-system/MASTER.md`)

## Files in this folder

- `visual-direction.md` — Design philosophy, references, what to embrace/avoid
- `color-and-typography.md` — Color palette and type system decisions (superseded by `design-system/MASTER.md`, 2026-11-14)
- `design-system.md` — Spacing scale, grid, interactive elements, component patterns (superseded by `design-system/MASTER.md`, 2026-11-14)

## Status key

- `[ ]` — Not yet decided
